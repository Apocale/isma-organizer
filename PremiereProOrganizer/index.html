Sorting rules
Sequences whose name has one of these words go to 01 sequence, even when another timeline uses them. Whole words: "Hook" matches Hook 1 and hook 7, not Hookah. Separate with ;
Sequences whose name has one of these words go to 08 nested sequence, even when no timeline uses them. Premiere's own "Nested Sequence 12" is always recognized. Any other sequence: nested if another timeline uses it, otherwise a main sequence.
Videos whose name contains one of these words go to B-roll. A word with a slash matches the file's folder instead: /B-roll/;/Stock/. TikTok and Pinterest downloads are recognized on their own. Separate with ;
Any file in a folder with one of these names goes to Exports, whatever its type.
Inside the audio bin: Music, SFX and Voice, by the words below. Off, all audio stays together.
Short words (under 4 letters) must stand alone in the name — "vo" matches vo_intro.wav, not love.mp3.
Bins and items with these names are never touched. Separate with ;
